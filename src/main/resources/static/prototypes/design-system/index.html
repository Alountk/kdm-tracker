Design tokens

Shared CSS custom properties for every prototype page. Defined once in tokens.css, consumed by this page and referenced as guidance by the four concepts. Every swatch below is rendered live — switch the theme to see both modes.

How themes work
  1. Auto default: with no stored choice, the page follows the OS via @media (prefers-color-scheme: dark) applied to :root:not([data-theme]).
  2. Toggle: the button in the header reads the effective theme, flips it, writes data-theme="dark" or data-theme="light" on <html>, and persists it in localStorage under kdm-prototypes-theme.
  3. Restoration: on load, the stored value is applied before first paint of the toggle label, so your last choice wins over the OS.
  4. Precedence: stored choice → [data-theme] rule; otherwise OS → prefers-color-scheme rule; otherwise light :root defaults.
// toggle behaviour (identical on every prototype page)
var KEY = 'kdm-prototypes-theme';
var saved = localStorage.getItem(KEY);           // 'dark' | 'light' | null
if (saved) root.setAttribute('data-theme', saved);
btn.addEventListener('click', function () {
  var next = current === 'dark' ? 'light' : 'dark';
  root.setAttribute('data-theme', next);
  localStorage.setItem(KEY, next);
});
