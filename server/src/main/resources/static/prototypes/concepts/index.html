Four design directions

Four competing concepts for the same two screens — Home (settlement list) and the Settlement Dashboard (11-step tracking). Same data, four different layout systems, typography voices and accents. Each is light- and dark-ready.

The concepts

01

Record Sheet

An homage to the official Settlement Record Sheet: warm paper, ruled lines, dense tabular fields, condensed small-caps headings and monospace numbers. A numbered left rail 1–11 reads like a printed form.

  • Layout: single ruled column + numbered rail
  • Type: condensed / small caps + mono numerals
  • Dark mode: candlelit ledger — near-black brown, amber accent
Home Dashboard
02

Guided Path

A wizard: one step at a time. A huge "Step 4 of 11" progress header, a vertical stepper rail, and the current step as one large focused card with Prev/Next. Decision steps are visually distinct from bookkeeping ones.

  • Layout: vertical stepper + focused card
  • Type: friendly rounded sans, generous whitespace
  • Dark mode: deep neutral + lantern-gold accent
Home Dashboard
03

Board

Tabletop-board-game flavor. A top pipeline of Settlement → Hunt → Showdown boards, the 11 steps as a tile strip with the active tile glowing, ivory/oxblood/gold palette and subtle decorative borders.

  • Layout: phase pipeline + glowing tile constellation
  • Type: display headings with decorative borders
  • Dark mode: night tabletop — deep green-charcoal, gold glow
Home Dashboard
04

Bento

A modern productivity app — Linear/Notion territory. Neutral gray scale, crisp sans, tight radii. The dashboard is a bento grid of widgets; the home is a clean card grid with status chips.

  • Layout: bento widget grid, tight radii
  • Type: crisp neutral sans, compact density
  • Dark mode: true dark gray + indigo accent
Home Dashboard
